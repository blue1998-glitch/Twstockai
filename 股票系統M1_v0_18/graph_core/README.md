# 獨立圖形辨識研究核心 0.1

這是可執行自動候選，沒有匯入人工案例、股票名稱或特定日期／答案。沒有修改原structure、attempt_evidence、MACD、策略、資料庫或歷史。工程完成與辨識品質／核心用途／交易價值分開；NOT_VALIDATED／NOT_EVALUATED／NOT_ESTABLISHED保持。

## 可重現數值契約

輸入`graph-recognition-input/0.1`：context必含code/source_id/price_basis_id/price_mode/SHARES_REPORTED；bars為有序完整日OHLCV原字串；as_of必須為確切供應日。Adjusted另需adjustment_anchor=as_of。可供expected_dates（已知預期交易日）、basis_break_dates及available_at。只讀as_of以前資料，拒不完整K／矛盾OHLC／重複日／無效基底或量單位，不造缺失K。缺價、缺已知預期日及明示基底變更切開結構，舊壓力不可跨缺口當作可比；Raw未驗公司行動另外保留警告，並非共同校正認證。

輸出`graph-recognition-research/0.1`：最新完成收盤錨、已確認與未確認高低點、反覆擺動箱候選、跨尺度包含關係、收盤離箱／跌回／破底與後續新箱、代表價候選、價量／後續跌幅證據、反證、缺證、研究比較與拒判資格。occurred_at與first_observed_at/confirmed_at分開；對未來確認的點不提前顯示。沒有唯一主壓力／沉澱／生命階段或交易建議。

## 明示研究設定，不是使用者批准策略

- 收盤相對過往極值反向3%／6%／12%作三個研究尺度。這是助手可逆探測設定，未從教材條件或人工日期答案擬合，也不是已核定的反轉／箱型門檻。保留全部設定於JSON。
- 每尺度先取因後續完整收盤確認的高低轉折；當日同時刷新極值並觸發反向時，因日OHLC無先後，延後確認並記歧義。相同價多來源日保留，未確認極值可替換且不稱已確認訊號。
- 箱幾何需至少兩個高轉折、兩個低轉折及共同的非空垂直走廊。高群／低群各自跨度不超全擺動跨度35%是研究穩定度設定。拒絕沒有反覆結構的單向走勢，不用固定月份／閱讀窗自動當正式箱。
- 每次新轉折確認，同時保留最長相容轉折串與最新四轉折局部種子，跨三尺度比較；歷史短箱不刪，長箱不因出現就取代小箱。這不是所有可能箱型的窮舉或已證最優分區，具體漏檢需保存而非調參湊人工答案。
- 每個候選的研究界線在建立時凍結。建立後才觀察收盤位置變更與跌回；歷史界線不因後來行情回寫。影線完整外包另供顯示，不等正式price_bounds（仍null）。箱在被突破／跌破後仍保存，後面可以生成新箱。
- 價量證據另存最新收盤與各離箱事件的原始當日量、排除當日的前1／5／20筆均量比，以及建立至後續最低的記錄數；這些不定義增量或急緩跌資格。區間證據分列記錄數、原始股數總量／均量／最高柱、與**前一個等記錄數且排除本區段**的均量描述比、缺量及其後跌幅。這些只是明示研究選段統計，不是正式整區量口徑、增量資格或精確套牢持股。缺量整段統計保持null，不以部分和當總量。
- 與最新收盤比較各候選的研究壓力帶與距離；上方相關壓力按轉折數、來源長度、建立後下跌幅與相對前段均量做多目標Pareto對照，不用單一分數、最近／最高／大或舊永遠優先。缺任一維度則不能宣稱支配，衝突保留。primary_pressure_id=null，正式重要性／衰減／權重仍未定。Pareto前緣是研究呈現候選，不是正式主要關卡認可。

純數值入口`analyze(payload, as_of=..., config=...)`不讀寫檔案、無網路／UI／資料庫相依，不接受manual_cases或references。`trace_reference`是另外可對任意明示價位核收盤事實的函數，不自動升格參照；人工案例對照只能在core輸出之外。

## 時點與限制

截短前綴的結果ID應與完整資料選相同as_of相同；追加未來或改未來不得回寫過去。同一既有候選ID的建立幾何不變，新增事件只出現在其後。實際歷史公布可得時間仍未核，這是依保存日線的因果運算，不宣稱已認證當時可交易資訊。日OHLCV不能推盤中先後或持股沉澱。
