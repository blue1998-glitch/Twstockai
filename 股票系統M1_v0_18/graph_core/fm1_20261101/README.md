## 真正可用的能力

`graph_core.market_daily`：六個官方整批來源取得／匯入→公司資料＋ISIN CFI普通股分類→日線品質→既有core0.2→逐股獨立終態→既有Journal不可覆寫保存。可承接同版本前次history、缺資料保留、來源修訂另版、同來源重送READ／0新核心呼叫。程式與引擎SHA均進批次身份；舊版本不自動重算／遷移。核心／策略／參數未改。

`graph_core.daily_update`：已準備單寫入鎖、明示保存head、每日六請求、續接、結果對帳及預覽；`daily.cron.example`僅設定範例，**未安裝／未啟動**。不假定目前容器可常駐或儲存可永久保存。

`graph_core.market_preview`：沿M-G3 render／互動／日K／量／MACD與SMA，加入完整母體搜尋、終態篩選及明示50筆分頁。無資料點選只顯示拒判，不載其他股／舊日期冒充。已知中斷使核心比較停止，MACD／SMA在新段重新暖機，不補價格或0。沒有排名、買點、資金規則或交易。

## 工程者執行（不要求使用者操作終端機）

於股票系統M1_v0_18、沿現有環境：

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m graph_core.daily_update --root /已核准的私用持久位置/twstockai-daily
PYTHONDONTWRITEBYTECODE=1 python3 -m graph_core.market_daily --root /私用位置 --fetch --parent-run 前次runID
PYTHONDONTWRITEBYTECODE=1 python3 -m graph_core.market_preview --root /私用位置 --run runID
```

無帳號／付費，六官方請求每次間隔1秒、無自動重試。latest端點不加任意歷史日期。範例cron保守安排台北隔日08:00；只接受早於台北當日的官方來源日期，不宣稱已驗收盤當晚最終公布。兩市場日期不同／未完成證據／未知週末交易日則停止。實際下一交易日尚未到，不聲稱已觀測；程式可再取得latest，但要待來源真的更新。

同版本parent承接完整保存歷史；同日來源改變要求`--correction-of 原run --correction-reason 理由`，舊結果保留，不把來源變更觀察當真偽認證。不同producer／引擎SHA的續接目前明確NOT_IMPLEMENTED，舊紀錄仍可由原Journal READ。本輪初始版本修正後已明示核對相同來源／終態／history keys，再初始化目前head，不是默默遷移。
