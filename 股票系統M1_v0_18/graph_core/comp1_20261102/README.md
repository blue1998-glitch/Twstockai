# M-COMP1｜同期多股量價研究比較工作台

[下載檔案頁：純合成手機示範HTML](Twstockai_COMP1_SYNTHETIC_DEMO.html)。在GitHub選「Download raw file」，下載後由Android檔案／下載目錄用瀏覽器開啟。程式碼頁不是執行網站；若拒開或顯示文字，回報畫面，不需修改安全設定。COMP1 Android實機未驗，不能借UX1使用者「操作ok」回饋稱新比較已實機通過。

## 可操作流程

搜尋或事件雷達→「加入比較」→底部「比較」→2～4股卡片。可移除再加入替代股；超過4檔明確提示、不自動替換。卡片「查看原圖與證據」返回既有圖，底部比較可返回原集合，不需重搜全部股票。比較集合及精簡證據只放當次記憶體，不寫localStorage／IndexedDB／SW或私人持久快取。

卡片保留原價、原量描述及來源、最新已確認高低點的全部並列、pending、原可比高點距離、原箱及位置／反證、原當期事件、缺日／中斷／來源UNKNOWN。絕對價格、股數、候選數及距離不直接比較強弱。未來報酬、剩餘空間、機率、買點、資金效率為UNKNOWN，排名為null。低點若原核心沒有距離欄位，不補新距離公式。

高低點／最近上方選取直接重用M-C2原邏輯`reference_summary`，只將原程式段抽成共用函式；原M-C2產物與語義不改。全部箱欄位沿M-C2 BOX_FIELDS與path_summary，不把不同股票箱ID當同一結構。完整歷史事件陣列及逐根K不存入比較物件；當期事件沿OBS1原結果整理。

## 同期資格

同一份`compare.js/comparisonScope`在正式頁、合成頁及Node定向控制共用：

- 日期不同、來源截止與分析日不同、RAW／還原模式混合、缺合格投影／來源、歷史不足→REFUSED，明示原因。仍可開各自有效的原圖；原來源拒用者維持原拒用，不硬開舊圖。
- 同日但觀察起點不同、來源種類不同／未知、跨基底／缺口、公司行動或歷史可得未核→LIMITED_DESCRIPTIVE，只作描述並列，不認證價量等價、期間統計優劣或策略有效。
- 各股票basis_id各自綁定原結果／主圖，不要求不同股票共用相同ID；完整source／result／prefix與基底均可展開回查。來源一致性不是來源真偽認證。

為讓日期不同的股票仍可獨立看圖，builder的圖形日期改取該股原result.as_of，而非將批次日期代填。原事件／結果不改，比較仍拒絕跨日。原stock.as_of與結果不符時投影／讀取拒絕，不找最近日期代替。

## 記憶體與安全

重用原分片與SHA／bytes／股票／市場／截止校驗。原loader拆出純讀取`readMarketStock`，比較依序讀每股，只留下最多4份精簡投影；不變更主圖data.series。切股仍由原取消序號控制，不能把比較讀取當選股成功。移除即釋放該股摘要，沒有無上限快取。只合成單檔內嵌虛構資料，正式懶載入不把全市場歷史塞入HTML。

新成品獨立`market-comp1-v02.html`；舊UX1／OBS1頁與原件不覆寫。原core0.2、MA、MACD、事件、private owner驗證／路由白名單與來源資格不改。不部署、不啟Oracle／VPN／排程、不購資料或交易。
