## 本輪實際新增能力

- 沿既有 FinMind 純轉接 helper、原 Journal、graph_core **0.2**、M-G3 圖與 MACD／SMA公式，加入免費**逐股**歷史協調器 `graph_core.market_finmind`。原限2884／固定日期的0.1介面與原碼前綴保持，另有明示歷史request介面；不改核心／策略、不建第二個庫。
- 每股先保存取得收據與原bytes，再比對同日官方原生價量，才分析並保存、讀回。逐股檢查點、來源／引擎／轉接SHA、實際取得時間及完整JSON指紋配對。失敗獨立留狀態；缺相依不自動重算修復。
- 同參照真實重送 **0次API／0次核心**。取回資料不重抓、未知取得狀態不重試；有單寫入鎖及每小時240次本機保守預算，低於官方無token300次。未使用token、註冊、付費或全市場整日下載端點。
- 全市場搜尋沿原預覽；195檔可開來源配對的K／量／MACD／原核心事件，其中193檔為多日且原MACD已暖機。相較原四股，新增**191檔可開圖（含2檔單日不足）／189檔多日研究**，不是只重算原四股。
- FM3按選股載入同源私人JSON分片，驗SHA256／bytes／股票／市場／分析日；只在記憶體保留目前一股，不裁剪原始K或核心候選／事件。讀取失敗隱藏舊圖，不用其他股票冒充。
- 原每日協調器另有明示 `--finmind-start` 接點，重用其六來源 capture／普通股分類，接本歷史RUN及私人預覽；保留原官方每日head，沒有強行把FinMind歷史拼入官方增量，也沒有改原預設來源流程。
