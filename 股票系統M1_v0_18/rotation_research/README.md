## 指標定義及重要限制

- `mark_equity`：現金＋應收款＋持股收盤市值；`net_liquidation_equity` 再扣全部現有持股的模擬退出成本，公平計入續抱方案尚未出售的負擔。終點退出是比較估值，不冒充實際成交。
- 淨價格報酬＝終點淨清算估值／決策日毛市值−1；實際模擬委託稅費、滑價、估計終點退出費分列。原始買入費與既有虧損屬共同歷史，不重收。
- 每筆交易日線性報酬、每交易日淨利＝上述事後結果／觀察筆數，不年化、不預測。固定5／10／20／40筆是評估尺度，不是持有上限。
- 最大回撤只用每日淨清算估值與初始資本，**不是盤中最大回撤**。`low_mark_bound` 是持股當日各自最低價同時發生的保守市值情境，不知道實際盤中順序，不能稱真實 MAE。
- `unadvanced_A_*`：A 收盤未超截止時凍結20筆原高時，實際仍持有的筆數、收盤市值×筆數、除初始資本×總筆數。這只是「未超實驗參照的占用」，**不是已驗弱勢持有時間**；分母不同、不當策略效率總分。
- 相對續抱、相對立即全換的期末淨值差額揭露事後機會成本；延後5筆提供固定延遲對照，未搜尋歷史最佳換股日。
- `loop.py` 用同一股數／現金／完整成交帳往前跑，零外部注資、成本逐筆扣除，未拼接獨立案例報酬。每10筆用之前5筆漲幅選實驗候選，全配／向候選移一半／兩者皆未漲則現金，整張與容量限制同上，只在檢討日調整。這**不是**已確認圖形策略，僅驗閉環帳務可運作；未有正式持倉管理、實際成交或飛輪獲利證明。
