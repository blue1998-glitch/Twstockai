# 週月均線獨立契約 v0.1

本版新增純計算模組 src/period_ma.py 與固定 JSON 接入器 src/period_jobs.py，不修改現有日線／結構引擎、stock-analysis/1.0 或任何 SQLite schema。沒有 UI、SQL、網路、策略分類或交易資格依賴。

## 輸入與輸出

工作單 schema 為 stock-period-analysis/1.0。必填欄位：schema_version、code、exchange、timeframe、price_mode、source、candles、corporate_actions、as_of；只有 calendar 為可選根欄位，未知欄位拒絕。timeframe=daily 表示輸入是日線；exchange 限 TWSE／TPEX；source 的 code／exchange 必須相同，id 與 volume_unit 必須明確。corporate_actions 只含 records 與 coverage_status，沿用 UNVERIFIED／CASH_ONLY_VERIFIED_SAMPLE；不自動核實或升級證據。

as_of 是台灣市場日期的當日結束，假設輸入日線已收盤；不是盤中時間戳。只取 date<=as_of 的價格與已生效事件。可用非交易日 as_of 檢查日曆週／月是否走完，但 last_price_date 一律保留最後實際價格日，不假造當日行情。

可選 calendar 必須有 coverage_start、coverage_end、expected_dates。日期須升冪、不重複且在宣告範圍內；空 expected_dates 只有在明確範圍內才代表提供的日曆宣告無交易日。超過 as_of 的日曆內容不進入快照，不能改變較早輸出。提供日曆仍為 SUPPLIED_UNVERIFIED，不能等同完整官方市場與個股停牌認證。整份工作單仍先驗證格式；前綴穩定性適用於合法的未來資料改動，不表示允許損壞的未來欄位。

純函式：analyze_period_ma(candles, events, code=..., exchange=..., mode=..., as_of=..., source_id=..., volume_unit=..., calendar=None)。回傳 period-ma/1.0、rule_version=period-sma-0.1-research、aggregation_version=period-bars-0.1；包含 weekly／monthly，每個有 bars、elapsed、candidate。

接入器 run_period_job(job) 回傳 period-analysis-result/1.0、adapter_version=period-job-0.1，包入完整 snapshot、來源、涵蓋狀態與 request_fingerprint／analysis_id。整份工作單含未來資料時 request 身分可改變；相同 as_of 的 snapshot 只依截至當時的價格、事件與日曆產生，不能受未來資料改動影響。

## 聚合與兩組均線

| 尺度 | 分組 | 均線週期 |
|---|---|---|
| 週 | ISO 週一至週日，跨年保留 ISO 週年 | 4／13／26／52 週 |
| 月 | 西曆每月首日至末日 | 3／6／12／24 月 |

每組 OHLC 為第一筆開、所有日線最高、所有日線最低、最後一筆收。先以該快照 as_of 錨定、套用已生效還原因子，再聚合；不能把單一週／月因子套在包含除息邊界的整根 K 線，也不能拿期末還原結果覆蓋早期快照。Raw SMA 沿用原始價格序列，不套用結構辨識的邊界重置。

週五仍是 OPEN_CALENDAR_PERIOD；到週日當日結束才是 ELAPSED_CALENDAR_PERIOD。月末依實際西曆日期。elapsed 不是「市場資料已核實完整」。elapsed 讀值只使用已走完的日曆期間；candidate 可含當前尚未走完的一根週／月候選，兩組明確分開，不升級成正式確認。

SMA 使用各期收盤的簡單平均，不用 20 日均線冒充月均線。先精確累加，最後除法以 28 位有效數字、HALF_EVEN；沿用既有日價還原的 28 位精度，且固定自己的 Decimal context，不受呼叫者精度／四捨五入／Inexact trap 改動影響。

curves 陣列對應完整日曆 bars，包括缺口列；point_status 解釋各位置為何 null。latest 明示對應期間、最後實際價格日、狀態及 window_periods。elapsed.latest 可能指前一個已走完期間，不能冒充本週價格。VALUE_AVAILABLE 只表示此計算窗口可得數值。

## 缺資料與成交量

- 樣本第一根週／月若從期間中段開始，且提供日曆未覆蓋期間起點至首筆價格日，標 LEFT_EDGE_UNCERTAIN，不算完整窗口。後續足夠期間才可形成均線。
- 缺整段期間保留 OHLC=null，不前值補價；未知缺口、提供日曆不符或不確定左邊界會中斷窗口。日曆範圍外不亂標「非預期交易日」。
- 只有已走完、日曆覆蓋完整且 expected_dates 為零的空期間，才標 SUPPLIED_NO_TRADING_PERIOD，跳過均線筆數而不造價格。沒有日曆時，不能猜空週就是春節休市。
- volume_unit 保留原生股數／張數已換算股數。聚合不乘除 1000；全部已知才有 volume_shares 總量。任何缺值使完整總量為 null；known_volume_sum_shares 另外列已知部分，不能當完整量。真實 0 與 None 分開。
