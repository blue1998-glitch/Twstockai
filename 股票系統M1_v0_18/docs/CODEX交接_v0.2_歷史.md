## 重現順序

1. python build_review.py （產圖另需matplotlib）
2. python validate_release.py
3. python -m unittest discover -s tests -v
4. node tests/check_viewer_syntax.cjs
5. 若有Playwright與可用瀏覽器：node tests/test_viewer.cjs
6. 工作單實跑：python src/jobs.py --input data/8069_job.json --output output/8069_標準輸入實跑.json

核心、工作單、覆核工具只需Python內建工具。不要為了跑核心而要求使用者安裝瀏覽器；瀏覽器只用於檢視頁QA。
