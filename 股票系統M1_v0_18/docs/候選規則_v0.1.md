# M1 價格結構候選規則 v0.1

狀態：研究實作，未凍結、未完成分類品質與交易價值驗證。預先記錄以下參數，不依本次兩檔樣本的結果挑選最佳值。

## 1. 轉折候選

近期波幅基準為最近20筆真實波幅的簡單平均。真實波幅取「當日高低差、最高與前收差的絕對值、最低與前收差的絕對值」之最大值；不是Wilder平滑版本。取得20筆資料後開始觀察。

兩個獨立層級：次級需要自候選高／低點反向收盤移動至少1.5倍波幅，並經過至少2筆後續日線；主要為3倍波幅及至少3筆後續日線。這些只是候選工程參數，不代表已驗證最適。輔助證據保存20筆成交量比、當日收盤方向及與前一個同類轉折的相對位置，不把它們加成總分。

候選極值出現更高／低價時，先追加舊候選被取代的事件，再建立新候選。波幅基準取新候選被觀察時的值並凍結至下次替換，不能只因日後波動縮小便自動確認。相同極值保留第一次發生日期。

初始化同時觀察高／低候選；若同一天兩者均滿足條件，輸出歧義並等待，不推測日內高低先後。確認一個候選後，只觀察相反方向。新方向的初始極值可位於先前已見資料內，但first_observed_at記錄實際建立日，不回填成當時已判斷。

規則成立時輸出`RULE_CONFIRMED_CANDIDATE`，意指候選算法條件成立，不能描述成已通過人工分類驗收、正式趨勢反轉或交易資格。

## 2. 價格區域候選

每個規則成立的高點產生壓力區候選，低點產生支撐區候選；上下界為極值±0.35倍該候選的波幅基準。區域寬度未驗證，不能描述成有效支撐壓力的統計結論。

僅從建立日之後開始記錄攻防：當日高低區間與區域重疊算接觸，連續接觸的數日算同一次接觸過程；另保存收盤在區域上方、內部、下方的變化。支撐區連續2筆收盤低於下界、壓力區連續2筆收盤高於上界時標示`BREACHED_CANDIDATE`，保留原紀錄。單筆越界後返回會重設計數。不得把突破區域直接轉換成買賣資格。

本版不合併區域，不進行角色互換，不分類三種正式整理型態；重疊或矛盾區域允許並存。成交量未提供到價位的分布，不能宣稱辨識了成交密集價區。

## 3. 價格模式與除息邊界

Raw與純現金除息還原候選分開執行。Raw模式遇已知除息日，停用舊區域、取消未確認候選並重新累積20筆波幅基準，避免把未調整的公司行動斷層直接當成轉折。

還原候選模式每個時點只使用截至該日已生效的事件，重新建立同一價格基礎上的前綴。每一天的歷史快照獨立保存；圖上可顯示當天尺度的歷史轉折投影，事件帳本則保留實際確認當日的數值。不能拿期末還原結果回填早期判斷。

繼承M0.7限制：純現金除息以外的公司行動、歷史公告時刻、來源修訂與完整交易日曆尚未認證。這是按生效日期重建的研究重播，不是已認證的完整時點回測。

## 4. 最低驗收

驗證高低點發生時間與確認時間分離、候選替換不覆寫、未來價格改變不影響先前快照、平台高點平手處理、同日雙向歧義、資料不足、錯誤與重複資料、Raw除息邊界、區域接觸去重、連續收盤失效與單次越界返回。

實際樣本為8069與6488各283筆。敏感度只比較不同波幅倍數下的候選數量，不依結果選出最佳參數，不計算勝率或聲稱交易優勢。視覺分類品質仍待人工覆核，後續必須加入不同股票及正反案例。
