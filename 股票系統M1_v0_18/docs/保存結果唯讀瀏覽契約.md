# 保存結果唯讀瀏覽契約 v0.1

此功能是離線研究工具。輸入為既有 analysis-store/1.0 SQLite 保存庫，輸出為獨立 HTML；不提供 HTTP 服務、不發布，不連線抓行情。數值核心、保存層、RUN／READ／LOOKUP 均維持既有版本。

## 匯出入口

```bash
python src/saved_viewer.py --db volume_revision/output/單位修正並存_v0_12.sqlite3 --output 成交量版本比較瀏覽.html
```

可重複傳入 `--record-id` 精確指定紀錄；不提供則捕捉開始列出的全部紀錄。重複、空清單、缺失 ID 均拒絕，不替換成其他版本。並行新增紀錄須重新匯出；這是固定保存清單的快照，不是持續更新檢視。

Python 函式：`export_saved(database, record_ids=None)`、`render_html(payload)`、`write_html(database, output, record_ids=None)`。資料契約 saved-analysis-view/1.0，接入器 saved-viewer-0.1。records 每項完整保留 AnalysisStore.load 的 bundle，含 request、result、evidence、rules、record_id、analysis_id、保存時間與理由。保存層檢查原始內容指紋及快照索引；這不等於來源真偽或分類品質認證。

只呼叫公開 list_records、load，以 mode=ro 開啟。沒有 recover、save、create 或引擎計算。資料庫缺失／損壞／版本不符／內容指紋錯誤／需要 hot-journal 復原時明確失敗；不刪除 journal，也不初始化資料庫。獨立工作程序可先執行下列既有復原入口，再重新匯出：

```bash
python src/store_cli.py recover --db 工作中的資料庫.sqlite3
```

CLI 成功退出 0、回傳紀錄數／快照數；錯誤退出 2，回傳 READ_ONLY_NO_RECOVERY。匯出路徑不得與資料庫、-journal、-wal、-shm、硬連結或符號連結相撞。輸出採同目錄暫存、fsync 與原子替換；失敗保留先前 HTML 和資料庫。輸出目錄必須存在。

## 瀏覽與價格基準

控制項為股票、價格模式、保存版本、保存日期。股票初始依代碼排序；單一版本第一次顯示最後保存日。多版本不論時間先後都需明確選擇。切換紀錄保留原日期；日期不在新紀錄中時清除舊數字並要求另選，不找最近日期、不擅選最新規則。前／後一筆與最後保存日只依該紀錄保存清單移動。

圖表只繪所選 daily_ma snapshot 原有 curves，完整價格基準由該日快照決定。小數二位是格式化，下載仍保留原字串精度。null 顯示資料不足，不填零、不把未保存的較晚曲線切回早期快照。均線週期直接取該保存規則；前端不做平均、事件乘法、轉折或區域辨識。

當日來源 OHLC 另列且明示原始價格，還原候選也不將其冒充還原 K 線。轉折、區域、待確認候選與當日事件完整沿用保存結構快照；發生、首次觀察、規則確認時間分開，不以確認日期回填發生時點。舊重播頁維持原樣，仍是原有兩檔資料的獨立歷史產物。

選取快照時檢查三份日期、snapshot ID、資料／有效事件基準、股票、模式、版本及來源 ID 對應。損壞／缺失時清除圖、數字、表格、JSON、懸浮讀值並停用下載。這些是連結檢查，瀏覽器不另做全部內容的密碼學驗真；勿將手改 HTML 當可信保存紀錄。

## 當日 JSON 下載

格式 saved-analysis-selection/1.0，包含 record 來源／規則／證據與 snapshot。snapshot 完整對應 AnalysisStore.snapshot(record_id, as_of) 的欄位和值，含 aligned、structure、daily_ma、各涵蓋狀態與 NOT_EVALUATED。下載使用本機 Blob，沒有寫回資料庫；頁面 CSP 禁止網路連線，文字以 textContent 插入，嵌入 JSON 的 HTML 特殊字元經跳脫。

## 已知限制與下一步

v0.12 保存庫為兩檔六組新舊分析、1490 個版本×日期，不是全市場。新舊版本比較 HTML 約 48 MB，整份載入；未實測低記憶體 Android 的載入耗時。真實 Chromium 及手機觸控驗收仍受缺少執行檔阻擋，Node VM 測試不能替代版面驗收。離線 HTML 需下載後用支援 JavaScript 的瀏覽器開啟，沒有已發布手機網址。

1101 來源 SHARES_REPORTED 是原生股數，歷史 structure-0.2 的 evidence.volume_precision 固定文字曾誤標換算。structure-0.3 新增明確 volume_unit，修正新結果的證據文字；舊結果不改動，舊版警示仍保留。詳見 docs/成交量來源與版本相容契約.md。

UNVERIFIED、NOT_VALIDATED、NOT_EVALUATED 仍有效；326 筆覆核目標未經人工驗收。沒有新增公司行動核實、週月均線、正式整理型態、買賣資格或績效結論。
