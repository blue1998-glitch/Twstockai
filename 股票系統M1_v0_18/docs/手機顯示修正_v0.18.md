# 手機顯示修正契約 v0.18

觸發：2026-10-17 三張使用者實機截圖顯示舊頁可用，但固定 900×300 canvas 經非等比縮放造成文字橫向變窄，長均線字串擠出主表。使用者明確要求小數兩位。

一般價格、均線、轉折價、價格區域邊界及期間 OHLC 顯示小數兩位，採十進位四捨五入。千分位只作閱讀格式；股數、計數、日期、ID 及版本不套此格式。null 不轉成零，保留原因。未知數字格式原樣顯示，不猜值。

保存字串、原分析結果、圖表坐標來源、指紋與下載 JSON 不改。例：原值 168.691666… 顯示 168.69，147.275 顯示 147.28；完整數字仍保留在 JSON。原 JSON 證據區維持原精度。主表欄名為「顯示值／原因」，明示四捨五入。

主數值表改為兩欄，週月所指期間／最後價格日移到數字下方，允許換行。完整技術明細仍可在各自區塊水平捲動。Canvas 使用實際 CSS 寬高與裝置像素比配置 backing，字體按 CSS 像素繪製。視窗改變時只用同一保存結果重畫，不讀新行情、不重新分析。保留原日線 Raw OHLC、Adjusted 未保存日 K 的限制、紅漲綠跌與缺值斷線。

原 HTML、模板和數值契約保留。原 render 預設輸出逐字相同，CLI --html 預設仍是舊版；新版需明確 --html --mobile。兩份模板皆受輸出碰撞保護。

驗證分為 Decimal 獨立參照、實際嵌入 JS 的 DOM/canvas 替身檢查、Python 唯讀與安全回歸、既有 Chromium 的真實瀏覽器驗收、實體 Android 驗收。各層狀態分開；不能用替身或舊版截圖宣稱新版實機通過。
