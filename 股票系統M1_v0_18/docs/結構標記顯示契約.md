# v0.18 結構標記顯示契約

使用者提供兩張點位、支撐／壓力色帶範例圖，授權把專案既有觀點放到 K 線圖。本次新增獨立成品「日週月研究對照_結構標記_v0_18.html」，沿用 v0.18 手機閱讀版，保留原頁與原手機版。

## 標記只呈現保存證據

- 主高／主低、次高／次低點，分別引用所選日線 structure 快照的 major／minor、HIGH／LOW、price、occurred_at；只有 RULE_CONFIRMED_CANDIDATE 可成為已確認歷史點位。未確認 pending 不畫成已確認點。
- 點位位置是發生日，確認日可能晚很多天。選單及點選明細分別列出發生、首次觀察、確認時間和原 ID，醒目說明不是發生日當時已知訊號。數字尾碼只用於本快照內的圖文對照，不是策略階段、分數或跨版本固定身分。
- 支／壓色帶直接引用保存 zones 的 low／high、created_at、invalidated_at、role、state 和 pivot_id。綠為支撐區候選、紅為壓力區候選；不重新計算區域寬度、不合併重疊區域、不做支壓角色互換。
- 色帶僅在建立日之後、失效／停用日之前的保存日期上繪製；視窗截斷不改原生命週期。預設只畫 ACTIVE_CANDIDATE；選「包含歷史失效／停用區域」才顯示原失效帶，以虛線框區分。沒有有效區域就顯示 0，不製造區域。
- 點選色帶或從證據清單選取，可看原日期、狀態、接觸次數及原 ID。交疊圖形可用清單明確選擇，不以最近價位猜一份保存結果。標籤為避免重疊可能省略，但點、原區域與清單保留。

## 範例圖的採用邊界

第一張圖只借用「點＋橫向區域」的視覺方式，不依示意折線自行產生 A／B／C 階段或平臺突破判定。第二張圖不構成已批准的「長紅 K 上方壓力」或「反彈無法收復」規則；本次不從單根 K 或圖形另造壓力區、交易資格或盤中先後。

週月引擎沒有保存對應結構轉折，本次僅在日線新增標記；週月保持原保存 K 線與均線。不可將日線點直接升格成週月結構或綜合方向。

## 價格、時間與互動

Raw K 線使用原 request OHLC。Adjusted 日線仍沒有保存還原 OHLC，所以只畫已保存 MA 與同一 adjustment_anchor 的 structure 點／區域，不在 JS 還原 K 線。原結構引擎在選取 as_of 的價格前綴上產生快照，標記讀該快照；不以事件帳本的舊價格代入，不在介面重新呼叫投影函式。

版本僅支援原已允許的 structure-0.2-research／0.3-research，錨定、日期或模式不符則不畫標記。空值或無法用有限座標呈現的資料不補零；完整原始證據與下載仍保留。顯示採原 v0.18 的兩位小數格式，計算座標使用原保存字串。

預設主要層級、有效區域、最近 130 筆；可切換次級／兩者／關閉，最近 60／130 筆／全部。這些只過濾畫面，不改 request、快照、版本或下載。選股、模式、日期、版本切換會清除舊圖及舊選取；CONFLICT 隱藏合併圖，不繼續畫標記。

日線主圖占完整列以便閱讀；canvas 保留原 CSS 尺寸／DPR 繪製、紅漲綠跌與 null 斷線。觸控點選與原生 select 均可讀證據，沒有外部資產或網路請求。

## 實作與重現

新模板為 src/cross_view_annotated_template.html，顯示邏輯為 src/chart_annotations.js；render 僅把受控本地 JS 嵌入模板，原預設 render 與 --mobile 輸出仍逐字一致。三份模板與 JS 都受匯出碰撞保護。

```bash
python3 src/cross_view_cli.py --config cross_view/sources.json --html --annotations --output 日週月研究對照_結構標記_v0_18.html
```

--annotations 必須配 --html；使用手機排版，可與 --mobile 同用。匯出仍是唯讀，不 import 引擎、不 recover、不 RUN。保存 JSON 契約、規則版本及數值完全不變。新 source checkout 用根目錄 `python3 codex/bootstrap_m1.py --hydrate-missing` 補齊被 Git 忽略的基準資產；它核對私有暫存基準，只補缺檔，保留並報告既有差異。預設 bootstrap 仍為嚴格基準核對，不能拿來覆蓋後續修改。

實際驗收範圍及證據見 annotations/validation_20261017/驗收報告.md。實體 Android 仍 NOT_TESTED。NOT_VALIDATED、NOT_EVALUATED、326 UNREVIEWED 與 SQLite 原事故 NOT_ESTABLISHED 均保持。
