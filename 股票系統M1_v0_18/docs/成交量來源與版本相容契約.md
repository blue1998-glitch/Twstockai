# 成交量來源與版本相容契約 v0.1

M1 v0.12 修正來源證據文字，不改候選策略、成交量數值或任何價格計算。新結構輸出版本為 structure-0.3-research；舊 structure-0.2-research 可繼續 READ／LOOKUP／瀏覽，不能就地改寫。

## 來源與輸入

| volume_unit | 數值意義 | 新證據 volume_precision |
|---|---|---|
| SHARES_REPORTED | 來源已提供股數 | Source reports shares directly; display precision retained; no lot scaling |
| SHARES_SCALED_FROM_LOTS | 上游已將來源張數換成股數 | Source lots scaled to shares; display precision retained |

兩者都已是股數，核心不再乘除 1,000。沿用 volume_shares_scaled 欄位名稱以保持既有資料契約；欄位名不能用來推測來源單位。None 仍是未提供，0 仍是真實零量。

JSON 工作單原本即要求 source.volume_unit，stock-structure/1.0、stock-analysis/1.0 的輸入格式不變。jobs.run_job 將它明確傳給 structure.analyze。直接呼叫 Python analyze 必須傳 volume_unit；省略或不支援的單位回傳 UNSUPPORTED_UNIT DataError，即使 candles=[] 也不猜測。私有 _run_prefix 的純數值測試若未提供來源，只標示 origin unspecified；不供保存正式來源說明。

## 輸出身分與保存

structure 根結果與每個 snapshot 新增 volume_unit。snapshot_id 指紋加入該單位，且 rule_version 由 0.2 改 0.3；相關事件帳本 event_id、aligned snapshot ID、analysis_id 因版本而更新。候選本身的 ID、發生／首次觀察／規則確認時間、參數指紋、價格、區域、成交量比、資料品質與全部日均線均維持相同。

修正版 schema 仍使用現有擴充欄位可相容的 stock-structure/1.0；producer 的 rule_version 明示語意修訂。統一接入器版本 analysis-job-0.1、daily-sma-0.1 與保存庫 schema 1 不變；不是資料庫遷移或新策略核准。

store_contracts 對 0.3 或有 volume_unit 的結構結果，額外核對根結果與每個 snapshot 的單位等於來源；缺失或不符拒絕保存。舊 0.2 無此欄位仍可完整讀回，不補欄位、不改原文。相同工作單可有新舊 analysis_id；LOOKUP 回 MULTIPLE_VERSION_MATCHES，不能自行挑最新。

## 重現

```bash
python volume_revision/run_acceptance.py
python saved_viewer/run_acceptance.py
node tests/test_volume_version_viewer.cjs
python -m unittest discover -s tests -v
python validate_release.py
node tests/check_viewer_syntax.cjs
node tests/test_viewer_logic.cjs
node tests/test_saved_viewer_logic.cjs
```

第一個命令只在獨立 volume_revision/output/單位修正並存_v0_12.sqlite3 追加新版本。首次由已關閉、無 sidecar 的 v0.10 來源庫獨占複製，保留舊完整 bundle；既有目的庫不重設。可 --db 指定另一份獨立庫，禁止與兩個歷史庫及復原檔同路徑／硬連結。不刪 sidecar、不假裝復原成功。新工作程序照既有 workflow 的 recover 邊界運作。

第二個命令預設使用新舊並存庫，輸出「成交量版本比較瀏覽.html」，報告為 volume_revision/output/保存結果完整比對.json。舊 v0.11 HTML、舊驗收 JSON 保留。v0.9／v0.10 驗收 runner 現在先檢查結構版本；新引擎下退出 2、HISTORICAL_RUNNER_VERSION_MISMATCH，尚未寫入。重現那些歷史演算法應使用對應歷史交付版本。

真實驗收比較 8069 Raw／Adjusted、6488 Raw／Adjusted、1101 Raw 五組，1311 份快照。compare.py 逐項限定允許變更：單位欄位、證據文字、版本及由版本衍生的身分；保留並完整比對所有候選 ID、價格、比率、日期、狀態、參數、來源、品質與均線。不能以「大致一致」取代。

## 頁面與限制

新頁面選單明示來源單位修正版／歷史保存版，多版本需明選。原生股數警示僅對舊結果保留，新 0.3 顯示已明示原生股數；下載 JSON 仍分別保留新舊原文。頁面只讀保存資料，不自行修正文案中的原始 JSON、不重算。

六紀錄共 1490 個保存快照，18 次首／中／末公開讀回及全部前端快照指紋核對。HTML 約 48 MB 全載入，沒有手機效能保證。真實瀏覽器／手機版面仍未驗收；本版未重試先前缺少 executable 的瀏覽器啟動。

此修正不核實資料來源真假或公司行動涵蓋、不提高分類品質、交易資格或績效。326 筆歷史覆核目標仍 UNREVIEWED，沒有把新版本標成已通過人工分類驗收。
