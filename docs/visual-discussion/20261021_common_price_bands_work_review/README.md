## 如何串起片段

1. 用新研究的完成收盤轉向，保留高／低平台、左右原日期與右側可知日；平台要等後來不等的收盤才可確認。原觀察首尾沒有足夠左右資料的極值不補成轉向，這不是原M1 pivot。
2. 相鄰兩個已確認收盤轉向，形成一段已完成上落的端點價位範圍。連續至少兩段才同時有上、下方向；這是本描述的數學定義，不是「兩段就正式形成區間」的策略門檻。
3. 對每個連續段序列取端點價位範圍的共同交集。交集有正寬度便保存一個候選，全部長度都留；相等僅一點，不當正寬價帶。它不是成交密集區、籌碼量或日內路徑。
4. 每個確切段序列有自己的不可變ID、原K價格外包與右側證據K。另列當前資料下尚能延伸多遠的最大連續序列；這個「目前可延伸範圍」會隨新資料改變，舊候選本體不回寫、較短候選不刪除，也不以最長窗勝出。
5. 回連前批已保存重訪見證，只接其參照價在共同價帶內、三段造訪在此價格路徑起點至右側證據日內、且在候選出生前已知者；共用來源不增加獨立支持票。

資料跨原列待核缺日時，不接轉向、段或共同價帶；舊人工較大時間涵蓋仍保留來源資格。這是資料隔離，不是市場被正式切段；完整日曆／公司行動／歷史公開可得仍未核。
