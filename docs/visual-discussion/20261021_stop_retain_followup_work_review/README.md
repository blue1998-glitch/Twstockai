## 新研究方法

沿用上一批未改動的反向外包候選生成函數，不輸入目標日期、長度或人工標籤。每個候選起日往後觀察，步驟如下：

1. 以已觀察日 K 的最低低點、最高高點組成價格外包。第一筆完成收盤嚴格在前一筆為止外包之外時，凍結該外包，記錄方向。
2. 後續若完成收盤回到凍結外包內（含相等），記錄返回並解除此次待觀察離開；若收盤先越到對側，另記方向反轉。不能用 OHLC 推測日內先後。
3. 若後來某筆整根日 K 嚴格在凍結外包的同一側之外，提出「舊觀察到前一筆停止」「本筆另列後續種子」「原較大範圍繼續」三個競爭選項，全部不選定。此事件後，延續觀察仍包括所有原日 K。

這是可重現的新研究假說，凍結外包不是已認可箱界／支撐壓力。整根事件必須晚於首次收盤離開，不能回溯把較早端點說成當時已知；沒有新增百分比或等待天數門檻，也沒有改原核心 2高2低、3／6／12%。新種子只有一筆，不代表已形成新區間、正式承接或父子關係。

## 實際驗證與保存

六個自動候選池共243次觀察、633個分支提案；它們互相重疊，不是243個獨立市場樣本或準確率。核對2284項事件幾何、633項分支一致性；六個指定範圍共208個去重逐截止檢查、歷史事件／提案ID不變、未來價格與未來列缺日污染隔離、正仿射價格變換，以及合成新低／相等／返回／反向事件。研究 driver 與驗證腳本各1次，沒有重跑前批362檢查或產品測試。

完整自動池以 [candidate-pools.json.gz](candidate-pools.json.gz) 保存（282244 bytes，mtime=0，解壓逐位元相等），避免把3.4MB文字檔拆成不完整摘錄；重現程式同時輸出完整原JSON。指定範圍完整軌跡見 [reviewed-scope-tests.json](reviewed-scope-tests.json)，統計見 [summary.json](summary.json)，實測見 [verification.json](verification.json)。PDF三頁已靜態渲染人工檢視，SHA與PNG綁定見 [manual-qa.json](manual-qa.json)，產檔修正如實記 [WORK_LOG.md](WORK_LOG.md)。Git固定提交回讀見本目錄GITHUB_READBACK.json。
