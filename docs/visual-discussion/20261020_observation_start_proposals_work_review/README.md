## 方法與比較

所有方法都只用所示截止日之前的保存資料。沒有把9/17、4/7、13筆、39筆傳入生成函數；這些已知參照只在生成完成後用來檢查涵蓋資格。

| 方法 | 只依資料怎麼提出起點 | 截至10/7的2884 | 截至6/2的ABC |
|---|---|---|---|
| 價格範圍向外推開 | 從右往左，遇到舊K高或低超出其右側截至當下的外包，保留該K及下一筆 | 66個候選，含9/17 | 25個候選，含4/7與5/13 |
| 收盤方向轉折 | 只用收盤方向切換；相等收盤平台須等右側不等收盤才提供證據 | 111個候選，含9/17 | 67個候選，但不含5/13 |
| 最新共同價位短窗 | 往左擴張，直到所有日高低範圍沒有共同正寬價位 | 只留下10/5至10/7，3筆 | 只留下5/28至6/2，3筆 |

「所有日範圍都共享價位」太偏向末端局部，不能直接取代較大觀察範圍；它仍可作短窗描述。5/13影線高31.40已被使用者選為局部代表，但當日收盤31.10低於5/12的31.20；只看收盤轉折會失去這種資訊。此處不新增自動代表點認證。

價格範圍方法保留的是觀察種子，不是已批准轉折：例如截至6/2，4/2原日低32.25高於其後4/7至6/2全段最高31.40，因此4/7被提出為後段觀察起點之一。這項關係只能稱在本次截止資料中可計算，不能倒稱當時已經認定整段區間或選成交易訊號。

## 事實與研究判斷分開

**已計算的事實：** 2884不輸入起日，仍得到9/17這個既有研究參照；ABC也得到原已選39筆涵蓋的4/7。4/7候選在5/14區內跳空之後仍存在，沒有因每次跳空都刪去較大觀察範圍。候選總數及完整來源理由保存於proposals.json，五個截止輸出見summary.json。

**研究判斷：** 相較只保留最新共同價位短窗，向左找價格外包擴張事件，較適合保留多種較大脈絡，值得作為後續區間形成研究的候選來源。這是探索性方向，不是三種方法品質排名、通用準確率或策略批准；66或25個候選仍太多，尚未從中選出唯一有用區間。

**尚未確定：** 哪些候選可組成有意義區間、正式成員、起末與價界、合併／延伸／停止、來源代表及重要性。9/17是原助手研究窗起點，使用者只確認10/7足夠辨認，不曾核定9/17正式起點；本輪不能把它寫成自動辨識命中正式區界。

## 終點限制已實際展示

截至6/2，方法提出4/7至6/2的39筆觀察提案；加入6/3後，仍會提出4/7至6/3的40筆觀察提案。使用者已確認6/3在前箱外，因此**截止日不能直接當區間正式終點，新提案也不能自動成為原ABC的延伸**。

兩個提案的識別碼與截止日分開保存，原39筆不會被40筆覆寫。不過這只是兩個已保存研究輸出，沒有建立正式結構的合併、承接或生命週期。共同起日也不證明兩個提案屬於同一正式結構。本批沒有修好終點判斷，已在verification.json明示限制。

同理，較短共同價位窗在5/14變成單筆，不會讓較大4/7候選被刪掉；但候選保留本身也不是正式父子歸屬認證。

## 資料涵蓋與當時資訊邊界

2884截至10/7原1207筆、目前保守候選可用段223筆；1101截至6/2的保守可用段139筆。可用段只從原已列待核缺日之後開始，避免候選跨過已知資料疑點；較早完整來源仍保留作背景與原研究，不把可用段起日當市場結構起點，也不降低舊大帶重要性。

這是研究用保守來源分隔，不代表完整交易日曆或公司行動已核。當時公開可得性亦未認證，列出的歷史缺日不等實際市場缺口。既有原資料與全部限制保持。

所有輸出是本輪新做的事後截止資料研究，不是原引擎歷史快照。10/7原核心／numeric_frame仍不存在，沒有被補造。historical_selection_time=null、historical_signal_eligible=false、primary_pressure_id=null。
