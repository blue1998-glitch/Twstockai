## 判讀上實際多保留了哪些差別

此次保存每個觀察起點的固定原始證據及逐日後續：何時低點穿價但收回上、何時收盤回下、何時重新收上、回下後是否仍未收復、當前相對位置、最低後續價與收盤，以及觀察到幾筆保存K。突破當天尚無後續，不預填站穩。後來返回不刪原當天已跨過，後來收回也不把修復倒填原突破當日。

具體後續價格提供新增支持或反面證據，並非單純時間經過提高確定性。14筆、5筆等均是本例觀察數，不是正式站穩／失敗天數門檻，也非獨立投票。觀察截至6/30仍為開放的歷程，不宣稱永續成功或永久失敗；正式holding_confirmed、success_or_failure及確認日期皆null。

量仍作背景，前輪量描述沿用、不重算。新後續價格視圖不依量能給否決；驗證將全部成交量改為1後，同一價格後續證據完整不變。這只是證明新研究程式沒有量硬門檻，不是證明低量突破在市場中的成功率。
