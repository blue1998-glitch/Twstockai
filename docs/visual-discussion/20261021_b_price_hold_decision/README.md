# 突破後站穩為結果依據；量能是支持證據，未放量不否決

使用者新確認：「是有帶量很好，沒帶量不一定就沒成功，還是看事後股價有沒有站穩突破高點價位」。此原則優先修正前輪可能將帶量當必要資格的解讀，不改原價量事實與先前人工答案。

## 已定的判斷分工

| 項目 | 保存的內容 | 依本次答案如何使用 |
|---|---|---|
| 價格跨過 | 對既定原高的價格是否已跨過 | 獨立於量能；不因沒放量就抹除已跨過事實 |
| 突破時量能 | 當時成交量及與明示基準的比較 | 放量可以支持判斷；未放量不能直接判失敗或排除成功可能 |
| 後續守價 | 之後股價是否站穩突破高點價位 | 是本次使用者指定的突破結果觀察重點，與突破當日分開更新 |

有帶量不保證成功，沒帶量也不必然失敗。此處討論未放大的量能，不把它偷換成無成交或資料缺失。成交量仍保留作支持或反面證據；取消的是「未達帶量條件就不能成功」的硬性否決，不是將量資料刪除。

「事後站穩」須依當時已出現的後續價格逐步記錄。不能看到後來站穩，就把原突破日改成當日已確認站穩；也不能看到後來返回，就抹除原突破日確有跨過的事實。突破發生日、後續觀察日與站穩判斷能確認的日期須分開。

## 套用到已核B路徑的範圍

沿前輪原K事實：6/9之後到6/30保存收盤均高於33.20；6/22收過35.50後，6/24又收回35.50下，但仍高於33.20。這些可作各層守價、返回的證據，不能用一個結果覆蓋所有大小層。此例33.20及35.50仍為研究原高代理，並非新核正式帶界；不將任何單日收上、固定天數或單次返回自行定為正式站穩／失敗。

已確認「後續站穩」的重要性，尚未定站穩所需時間、允許的影線／收盤返回、深度、重新收回的處理及正式確認條件。保存觀察事實即可，不先發明N日、百分比或倍量門檻。人工觀念已答，不應因數值未定再問同一觀念。
