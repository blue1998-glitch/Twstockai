# 離開之後的持續追蹤：返回、停留與後續種子

本輪把停止提案之後的參照保留下來，能隨新資料區分「碰到舊邊界」「完成收盤返回」「持續在外」，並追蹤新種子自身的收盤往返。**正式終點及自動分類仍未定。** 新增的差異證據不回寫較早截止，也不推翻已答ABC39或G2時間涵蓋。

## 這次增加的研究能力

上一批遇整根離開後便清掉待觀察框，仍保留原事件與三種競爭分支。本輪直接讀取那批不可變事件，另建持續追蹤；原方法、輸出與核心都未改或重跑。追蹤所用的參照是首次收盤離開前凍結的原始高低範圍，不是正式箱界。

- 每筆後續日K記錄整根是否仍在離開方向、日範圍是否接觸跨越價位、完成收盤是否回到凍結框內或越到對側。相等算接觸／框內，不補成越過；OHLC不推日內次序。
- 首次碰邊、首次收盤返回分開。原離開事件不因後來返回而消失；返回也不是正式合併、必須延長區間或自動解除既有停止的命令。
- 新種子累積自己的完成收盤轉向，平台必須等後來不等的收盤才可知；同時見到高低兩方向只是一種路徑證據，尚非「區間已形成」。這是新收盤研究事件，不是原引擎pivot，更不能取代5/13的最高影線代表。
- 到原列待核缺日便停止跨越該處的後續追蹤，保留缺口資格。日曆／公司行動／歷史可得仍未完整驗證；沒有列缺日不代表來源已完整認證。

## 同一價格不能灌成多票

ABC截至6/3，有24筆候選觀察同日觸發整根離開，但只跨越28.45、28.70兩個價位。2884截至10/16，有59筆同日事件，只跨越47.30、47.35。它們來自多個互相重疊的起日、共享極值，不能說24票／59票證明停止。

本輪依股票、事件日、方向與跨越價位歸組，保留所有成員、完整上下框與邊界原K日期。這只是相關證據的索引，同價位的不同來源仍保留，不自動合併正式結構；兩組也不等於兩個獨立樣本或固定層級。完整六池633筆觀察事件歸成119個池內價位群組，跨截止還會重疊。

完整成員見 [boundary-families.json](boundary-families.json)，六池後續摘要見 [pool-followup-summaries.json](pool-followup-summaries.json)，八個指定截止的完整逐筆路徑見 [selected-followups.json](selected-followups.json)，[summary.json](summary.json)保留統計。沒有刪候選、打分排名、增加概率或強制選分支。
