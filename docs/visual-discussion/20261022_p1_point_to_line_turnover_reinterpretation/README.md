## 已確定的圖形判讀與唯一錯誤

1. 使用者認可示意圖 **A、B 除了 B「換手」標註外的其他整體畫法**。包括 A 急漲高點（點）→橫向整理（線）→後續上攻／階梯抬高，及 B 高檔活動、跌破整理下緣、之後反彈弱於前段的**事後完整路徑**示意。這是對圖形方向的人工認可，不表示使用者授權圖中每個定量門檻或「高檔出貨」能在當時被預知。
2. **B 圖高檔大量出現當時**，只可記錄「成交量明顯放大、所在價格區及 K 線行為」。當下**無法得知換手是否成功**，因此原圖指向大量處的「高檔大量、換手」若隱含成功換手或確定換手成立，是**錯誤標記**；禁止把 `SUCCESSFUL_TURNOVER` 或已確立的 `DISTRIBUTION` 倒填為當時即知的分類。
3. **後續價格跌破原整理箱型下緣**，使用者才把當初那批大量**重新解讀為未消化賣壓／套牢量**，而不再把它理解為有利的成功換手。這是**事後出現新的價格反證後，量能角色改變的人工結構解讀**。
4. 「套牢量」是使用者的經濟含義／賣壓候選，不代表每日 OHLCV 能精確量測現存套牢股數、真實持有人或辨明所有當日成交者是否仍持股；引擎對此標記應附證據、時間與不確定性。實際當日成交量的數值及當時價位事實始終不改，只有後見解讀更新。
5. **反方向也不可先驗**：單看整理期間量縮或高檔放量，不能預知後來一定突破或跌破；後續若價格越過前高並守住，才累積結構轉強證據；跌破箱底後轉弱，跟已定的 P0-3 只依價格事實更新一致。

| B 高檔出現大量的當日 | 量柱放大、K 線形狀、相對箱界價位 | 交易活躍；換手是否有效、後續是整理或賣壓仍未定 | 畫「成功換手」、提早確定出貨或套牢 |

## 本次增訂：觀察事實與經濟解讀必須分離

- 只讀數值引擎至少區分 `volume_observation`（當時量柱數值＋所屬 K／價位）、`structural_observation`（高點、整理上／下緣、跌破、反彈）、`volume_role_interpretation`（未知／可能換手／潛在套牢賣壓／後續再轉換），並保留各自的`as_of`可知時點、來源價格基底與研究版本。
- **不得依歷史事後結果編造盤中當時預測準確率**。未破底之前不能把 B 量柱標成當時已知的出貨/失敗；回測重播必須先截止快照再逐日更新，不借未來價格。
- 若之後又轉強，壓力／支撐角色可隨價位與後續換手再更新，不能讓「套牢量」永久不可逆地釘死；不假定價格跌破即精確量化未出清股票。
- A 的「健康整理／階梯再攻」與 B 的「破箱轉弱／反彈受壓」應保存為兩條**最後走向不同**的歷史示意，不能把後見 A、B 標籤倒灌到早期相似走勢。
