## 箱底來源的三種待驗解釋

| 候選 | 紫／褐下緣可能如何選 | 當時可知與失效風險 |
|---|---|---|
| 階段回檔低點 | 找各自高點後、整個階段向下回檔的低處；再觀察附近是否走平、回升或多次接近 | 最低點發生時尚不知道它是完整箱底；後續更低價需要版本更新，不能倒填到高點當日 |
| 突破的起漲支點 | 用越過較早高點之前的轉折／出發位置定位下一箱的下緣 | 褐箱若以舊紫階段的出發低點為底，可能把前後箱混成同一層；本圖並未授權這種繼承 |
| 後續支撐群 | 以回檔後相近低點及後續守住的 K 群決定可觀察底部範圍 | 需要後續證據；可與單根最低影線不同，也不能要求固定次數或天數 |

三者是**助手提出的對照問題**，不是使用者三選一、更不是程式可直接採用的公式。大箱可有一個「曾到過的最低價格事實」及另一個「因反覆活動而更有結構意義的底部區域」；兩者是否分列、何時有足夠證據、紫／褐是否各用相同判準，仍須由使用者在原圖指出。灰箱即使與褐箱某段下緣接近，也不推定所有褐箱底都由灰箱決定。
