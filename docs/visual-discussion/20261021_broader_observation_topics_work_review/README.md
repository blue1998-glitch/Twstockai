## 「足以另提」的精確界線

1. 指定的新活動必須在當時已有完整右側證據。只完成離開、單根創高低、尚待確認，都不補成完整後續。某提案的「first_reviewable_on_saved_bars」只指這組支持證據完成日，不是市場最早辨認日或歷史曾選取。
2. 新提案必須帶出可檢查的前後關係：不同價位的完成活動，或固定框與同一離開歷程中的外側完成活動。前者可能仍完全位於既有較大結構內，後者也可能是較大結構內的異質片段。
3. 較大閱讀範圍的起點按支持證據來源回連，出生終點按完整證據日；原值最高低只作閱讀外包，不當正式價界。完整證據日也不是正式結構終點。
4. 返回、現價離開局部核心及後來新增資料改變當前觀察，不回寫出生證據。若舊追蹤沒有覆蓋截止，仍保留UNKNOWN，不把最後開放狀態當現況。

因此，本輪沒有一例足以新增「正式較大結構已成立」的判定。已能提出有來源、可回讀的對照範圍；接下來要研究多段活動是否持續受相同較大原參照約束，不能靠換個較大窗口就宣稱找出整體。
