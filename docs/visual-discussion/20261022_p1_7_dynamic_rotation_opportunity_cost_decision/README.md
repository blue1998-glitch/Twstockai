## 已答：方向性判斷，不能擅自轉成硬排序公式

1. **跨股相對強弱**：判斷新候選 B 是否比原持股 A 強勢，需要比較同一截止時點的價量結構與動能，並保留證據來源及反面。
2. **原持股等待價值**：不是只看 B 強不強，還要問 A 是否已經不值得繼續等待，包括原持股目前轉強／整理／轉弱位置與資金卡住的機會成本。不能憑歷史虧損百分比直接認定 A 失效。
3. **關鍵位置及過線事實優先**：使用者明示「誰更靠近關鍵位置，並且價格已經超越了關鍵位置，順序應該排在前面」。此處是人工比較優先的方向，不是只要靠近阻力就買；還要區分接近、真正過線、返回及是否守價，並考慮突破後下檔風險與尚存空間。不得自訂固定百分比或排序權重。
4. **時間與資本效率是目標**：使用者期望比較在一定時間內哪個選擇使資金成長效率較高，但明確表示**目前沒有辦法可靠衡量未來一定期間會賺多少，尚無最佳方案**。不能將此願景寫成已驗證報酬預測或「B 一定比 A 快／賺更多」。

## 尚未裁決：部分換股是否較好

- **歷史習慣（描述性）**：使用者過去多採「全賣全換」。
- **目前探索意向（非策略批准）**：認為應研究分批機制，但不知道哪種方式好，未核准固定分批次數、單次比例、觸發門檻、資金上限，不能擅自把「應設立」誤寫為已批准正式分批執行規則。
- **待比較的競爭方案**：①全換；②分批由 A 向 B 轉移；③賣 A 後暫持現金；④續抱 A；也可含部分 A＋部分現金／B。這是助手提出的研究方案集合，不是使用者已批准使用的交易策略或自動下單。

## 需要明確修正的損失比較（助手分析，非假裝使用者逐字答覆）

過去已實現／未實現的價格損失必須呈現，但換股決策應將**目前可動用的相同資金**在同一起點比較 A、B、現金。原始買入成本屬歷史資訊，不能要求 B 必須先賺回 A 已虧部分，才認定換股值得；此為常見沉沒成本陷阱。

比的是「從現在開始的未來淨績效與不利情況」，不是保證 B 在 N 日後一定賺過 A。手續費、交易稅、價差／滑價、部位限制、流動性、假突破風險及可能回補 A 都必須納入，且對分批增加的交易次數做成本檢查。不能為了證明分批有用任意用同一回測的最佳門檻回填到當時。

## 建議的實驗設計（尚未回測、非固定交易規則）

研究引擎應在每個**歷史決策截止點**用當下能知道的原始 K、價量、結構、持股市值與風險資訊，保存：
1. A 的當時結構、下一個關鍵點、等待價值與結構破壞風險。
2. B 的當時候選結構、是否已過關鍵價、當時動能品質、追價風險與流動性。
3. 同額資金不同去向：繼續持 A／一次全換 B／研究用分批換 B／暫持現金，彼此比較的條件及交易成本。
4. 各個候選決策可用的資訊日期、採用的 Raw／Adjusted 基底版本（嚴禁混基底）、模擬可成交時間與成交成本、規則版本、持倉快照及完整資金流。
5. 在**不偷看未來**條件下，後續對不同時間尺度分析淨收益、最大不利波動、資金占用天數、換股次數、交易成本及相對 A／B／現金的機會成本；分不同市況及結構做樣本外測試，不能把某一段回看最高報酬稱為可預測的未來回報。
6. 分批候選是**由客觀事件觸發**的試驗性比較項目，例如第一階段 B 超越關鍵點而後續守價、或 A 結構再被破壞等「等待下一新證據」條件；本文件不設定固定 %、批次或保證時間，具體公式需實證後才可提出供使用者核准。

## 概念架構的必要分離

- `relative_strength_evidence`：A/B 價量與動能相對證據，不等同交易指令。
- `incumbent_hold_value`：A 的持有資格／仍值得等待的證據，不因虧損就歸零。
- `candidate_entry_readiness`：B 的關鍵價、確認程度、仍可上攻空間與跌破風險。
- `capital_allocation_candidates`：A、B、現金、多段轉移等**可比較方案**。
- `net_outcome_by_horizon`：只在事後回測取得；不能拿事後已知最高獲利倒填原先預測信心。
- `rotation_policy_authorization`：正式資金配置及自動執行 **NOT_APPROVED**，不得因本輪探索發出全賣或分批交易指令。
