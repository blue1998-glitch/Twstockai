## 已答內容與前輪修正

B幾個月整體歸屬問題已答，狀態ANSWERED_NESTED_LARGE_AND_SMALL_BANDS。使用者選方案二的理由，是保留較大帶內的小帶；同時認可方案一所表達的大帶存在。先前將「合成一個大帶」與「小帶分別存在」設為互斥選項，並把方案二稱作三組各自獨立的平面並列，需修正。

此例採有層次的讀法：較大價格帶作背景，內部多個小帶各自保留身份與突破觀察。保留大帶不應抹平小帶，辨認小帶也不刪除大帶。不是只保留一個大框，也不是三個互不隸屬的獨立大帶。小帶數目不被前輪三個月份閱讀段限制。

| 層次／事件 | 使用者已確認的研究意義 | 尚不能直接推出 |

| 大帶內有小帶 | 大小範圍可以同時辨認、分層保存 | 由包含關係自動生成所有正式父子ID或價界 |

內部小帶的帶量突破，可能在尚未觸及大帶邊界前就有研究價值。因此不能將「在大帶內」或「還沒觸大帶高低」寫成所有小帶一律無用的通用過濾條件。原4/16～4/27微小波動的本例答案仍保持，不把每個任意小框或前輪月份段都追認為已核小帶。微小價格擺動、可辨認小帶、小帶突破及大帶突破要分開記錄。
