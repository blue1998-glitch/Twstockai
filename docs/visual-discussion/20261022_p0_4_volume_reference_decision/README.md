## 二、已明確回答的系統概念

### 1. 兩道量比較基準，非二選一

- **密集量峰代表線**：用一群量柱的相近高點做視覺參照；當最新量跨越該線時先開始注意（早一階段支持證據）。
- **同一所分析價格帶的最高量**：單獨保留其原始日、價量情境及數值；若當前量連最高量也超過，是比只超代表線更強的量證據，人工稱「最好」。
- 不准把「必須超越最高量才有效」做成必要入場或突破成功門檻；也不准只留最高量而抹去密集量峰。
- 在案例中，1.5 億股高於 1.1 億股代表線但未高於 2.8 億股最高量：記錄兩個**獨立且同時成立**的比較事實，前者正向關注，後者只是「尚未跨最高量」，不加負面判決；繼續觀察價格向上推進。

### 2. 異常大量不可排除、不可機械降權

- 使用者明確反對「極端大量遇到長黑／跳空／急跌就忽略或排除」。**所有量柱都要保留，因為各自帶有不同價位、K 線及後續交易脈絡**。
- 下跌伴隨大量時，使用者視覺判讀為「套牢量／未消化賣壓」的重要候選來源。應記錄**量發生的價格帶、當日 K 型、後續是否反覆換手、價格相對該帶的方向**；不直接拿它取代密集量峰代表線。
- 注意事實與推論界線：「量柱大且當日下跌」是可測的價量事實；「實際有多少人套牢、賣壓被消化多少」尚不能僅由 OHLCV 證實。保存為人工經濟含義／壓力候選，勿冒稱已量得剩餘籌碼分布。

### 3. 量與價位的角色會轉換

- 成交量意義不是固定「大量＝好」或「大量＝壞」；當前價格的位置、舊成交密集帶以及持續換手決定它是支持、待消化壓力，還是隨越過／跌回而改變角色。
- 「原來支撐可以變壓力、壓力可以變支撐」是人工確認的**動態價量角色轉換原則**；不能由一次量增、單日突破或一天跌破自動認定轉換已獲充分證據。
- 人工關心的是**市場是否持續出現願意以更高價格交易的買方**，以及後續價格是否能推進／站穩；此為觀察目標，不等於具體判準或已驗勝率。

### 4. 密集量峰紫色虛線的畫法

- 使用者明確確認**本張模擬圖中的紫色虛線**符合其視覺畫法，約位於 1.0～1.2 億股密集量峰附近（圖上畫約 1.1 億股）。
- 這核准的是**此範例的人工示意位置及方法方向**，不是任何股票都使用「1.1 億股」、「最高量的固定比例」、「20 日平均量」、「中位數」或固定密集柱數的自動線。
- 正式程式仍須研究：哪些量柱屬同一可比群、如何量化視覺相近量峰、不同價格帶的量比較資格、來源時間可知性及量資料單位。

## 四、面向數值引擎的候選輸出（工程提案，不是新已核門檻）

對於一個已識別的價格帶，保留：
- 該帶及截點、所屬價格基底／成交量單位／來源；
- 密集量峰代表線候選及來源量柱集合與首次可知時點；
- 最高單日成交量及其 K 線／價位／日期；
- 最新量與代表線、最高量分別比較（是否「大於」與實際差額，不轉化為單一真假成功旗標）；
- 異常量與其價格區域關聯、長黑／跳空／急跌事實（如適用）；
- 市場當時相對價格帶的上方／內部／下方位置、價位再訪、重新突破與是否持續換手的可見證據；
- 人工經濟語義候選（支撐、套牢壓力、待消化、角色翻轉）、證據品質與限制，**不偽裝實際持股／賣壓量測**。

分類狀態至少分為 `OBSERVED_VOLUME_FACT`（量價可見事實）、`HUMAN_INTERPRETATION`（人工意義）與 `UNVALIDATED_ENGINE_HYPOTHESIS`（未驗證規則）；不替使用者指定「N 根量柱」、「倍量」、「幾日換手」門檻，也不把跨量柱當自動進場。
