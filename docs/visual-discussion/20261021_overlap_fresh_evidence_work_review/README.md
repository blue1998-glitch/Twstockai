# 影線仍交疊時：是重用路徑，還是全新的活動證據？

**影線範圍交疊，不妨礙後續活動價位移動；但要先分清楚後段是否重用了較早的走勢。** 本輪把「共用完成段」、「沒有共段但來源期間仍重疊」、「完整來源都在較早候選可知之後」分開，提出局部角色候選。這不是正式拆箱、合併、主要性或區間分類器。

三頁可放大[PDF圖冊](output/pdf/m1-overlapping-ranges-fresh-evidence.pdf)；[ABC全新向下移動](page-1.png)、[G2實際造訪與幾何交集](page-2.png)、[B共段與A重用來源](page-3.png)。完整接續見[WORK_HANDOFF](WORK_HANDOFF.md)，實測見[verification](verification.json)，同分支回讀見[GITHUB_READBACK](GITHUB_READBACK.json)。

只讀531個既存共同候選及其200個研究收盤轉向／195完成段、原價量，不重算原M1 pivot／box或舊候選生成。限於曾在同一保存觀察窗共存的候選配對，不把不同任意窗湊成市場比較；同一可知日不指定先後。這些觀察與候選有大量重疊，不是獨立市場樣本或多張支持票。

| 來源關係 | 判別方式 | 可以說什麼 |
|---|---|---|
| 共用完成段 | 前後候選含相同leg ID | 同一走勢被不同組合涵蓋，可比較價位，但不是兩份全新往返 |
| 無共段、來源仍重用 | 後段首轉向的左側證據日不晚於前候選可知日 | 有新增完成段，完整來源仍含較早期間，不能說全是之後的新證據 |
| 完整來源較晚 | 後段最早左側證據日嚴格晚於前候選可知日 | 可另看全新完成雙向活動是涵蓋舊價格、向上移或向下移；不自動判正式區間 |

「完整來源較晚」只說輸入日期沒有重用舊期間，**不代表統計獨立、較可信、比較重要或可交易**。後段核心相交／僅碰／嚴格在上或下，以及兩段影線外包交疊／分離，各別保存；不要求所有區間都得影線完全分離。

共同價域是完成收盤端點域交集，**不是成交分價、日內路徑或已發生收盤返回**。全新來源的正寬價域重疊配對中有229個「後段路徑內沒有實際保存收盤進舊核心」；這是重疊配對統計，不是獨立案例或市場發生率。不得由此反推盤中從未成交，也不能用確認K入內回填較早路徑。

共259保存觀察（243舊池＋16外部指定窗），60,483個嚴格較晚的去重配對；743同日可知配對不排序。3,948共段、2,638無共段但來源期間仍重用、53,897完整來源較晚；984配對跨原列待核缺日，價格比較保留但不證連續性。沒有選最重要主區間或新增交易參數。
