## 對讀法的結論

四個新後續查詢沒有發現這套分層讀法的時序矛盾；它能描述向上、向下、後來收回與目前尚無足夠後續的不同情況。這是有限事後指定案例的一致性檢查，並非新案例盲測、全市場有效性或成功率驗證，亦未把上下方向相反直接當交易規則相同。

可供後續實作的最小語意已收斂：每項證據必須綁原參照／來源、觀察起點及截止；固定起點事實，後續更新目前位置；影線穿過、邊界恰等與收盤跨回分開；支持只對準相應參照，較早／較大範圍另保留未解證據。新的反向收回可以當下改變「目前仍在下方」的描述，歷史下移仍在。這些是價格事實與證據解讀，不是正式生命階段、站穩或行動分類器。
