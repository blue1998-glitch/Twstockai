# 離開後的局部活動：什麼證據支持另列候選？

**可以先保留舊參照，再另列「已在外側完成雙向活動」的候選。** 本輪提出可重現的有限正面條件，並將每次返回後的再次離開分開，避免把幾個月後的新活動補成第一次離開的持續證據。這支持角色候選，不裁定正式新區間、父子、舊區間終點或交易資格。

三頁可放大[PDF圖冊](output/pdf/m1-separated-followup-role-proposals.pdf)；[ABC正面例](page-1.png)、[G2返回與另次離開](page-2.png)、[2884與方向對照](page-3.png)。完整續接見[WORK_HANDOFF](WORK_HANDOFF.md)，實測見[verification](verification.json)，保存回讀見[GITHUB_READBACK](GITHUB_READBACK.json)。

本方法只讀先前保存的整根離開事件及共同往返候選，不重跑原核心／舊候選生成，也沒有新行情。原凍結框是先前觀察外包，非已批准箱界。

1. 原框已有整根K在某一側之外的保存事件。
2. 對同一固定框，逐筆記錄收盤仍在該側的歷程；收回框內或收到對側就結束這一次。影線觸框而收盤仍在外，另記接觸，不能當收盤返回。已列資料缺日則停止連續性，不當價格返回。
3. 在某一次歷程中，先有整根在外，再有已保存的兩段以上共同往返；該完整路徑的影線外包也必須嚴格在舊框同側之外，才另列「外側局部活動」角色候選。若確認K當天已收回，保留「已完成外側活動，但確認時已返回」的歷史角色，不冒稱仍在外。
4. 出生證據與當前角色分開：後來返回可更新目前位置與歷程狀態，不能刪出生證據或直接正式合併。較大人工整體與較早主要參照繼續保留。

「外側活動」是本輪比較**局部角色**的正面條件，**不是所有整理的必要條件**；原ABC39筆、G2人工136筆和2884已答整理都不降回待問。它也不是在全部候選中選最重要者，不能以新、近、數量、同價或單一幾何關係取代舊主要帶。

本輪遍歷637個既存事件截止觀察（原自動池633出現＋外部案例新增4出現），357個去重原整根事件、503個池內歷程出生、531個既存zone；10,175個去重活動角色連結，另存13指定截點。事件、候選及截止有重疊，不能當獨立樣本或多張支持票。儲存索引不表示優先級。
