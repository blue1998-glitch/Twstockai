## 最高量與視覺代表量位分開

帶內最高量屬於哪根K，要用該帶的成交量找，不借最高價K代替；若同最高量有多日，保留全部日期。價格高低、量峰及所屬帶範圍都要綁原來源與截止，不能回填未來才知的整帶量基準。正式帶成員尚未定時，不在任意小框算數字就冒稱整帶最高量。

使用者所說整體均量，是由密集量柱的相近高點辨認代表量位、畫一條量線。先保存為**視覺代表量位**，保留支持它的量柱日期；不能未經檢查就換成算術平均、20日均量、中位量或固定倍數。以前三種量比較仍是描述資料，不因新方法自動取得正式資格。

原話「右邊的量也超過該均價或是該價格帶的最高點」完整保留。因句中混用價格與量的詞，系統目前只做量綱分開：價格與相關高點比，成交量與代表量位／帶內最高量比，不把量數字拿去比價格，不擅自改成VWAP。價量兩項怎麼結合、兩種量參照的正式或／且條件、代表線算法與門檻仍未定；此處是助手為避免不同單位混算的解讀，並非使用者額外核准的數值規則。本輪不因此重問例行細節。

新方法保留先前已答原則：帶量是支持，沒有放量不必然失敗；價格確已越過的事實不因量少抹去，仍看後續是否站穩突破高點。後來守價結果不倒填突破當日，返回亦不刪原已跨過。
