## 分析：哪一部分有區辨力，哪一部分不能單獨判斷

**價格範圍的重疊只描述幾何。** A、B兩個重疊量相同，無法用這兩個值表達末段方向的差異。同價位涵蓋計數本來也不記錄日序；保留同一組範圍而改變順序，這個數字不變，但路徑可以不同。它不等於實際成交集中、成交量分價分布、持股成本或籌碼沉澱。

**較廣與較短觀察必須並存。** A末3筆連續收高，與更大背景中的整理可同時成立。完整列出3至13筆的所有尾段描述，沒有挑8筆當最佳窗口，也沒有指定任一比例當整理門檻。這是觀察窗敏感度研究，不等於原3%／6%／12%轉折尺度、日週月整合或跨尺度正式歸屬已完成。

**末端回穩證據不能決定所有區間是否存在。** 原已確認1101 ABC自己的區間包含6/2；當日低27.65是這39筆最低、收27.70。故「必須先不創低才能承認任何區間」會排除既有正面案例。本例不另外定正式破底價界，不推6/2為新解除事件；6/3在前箱外的既有裁決仍保持。

B同樣可能包含區間或呈現區間後轉弱，沒有人工標籤不能當整理負例。它在這裡只對照「末端繼續向下推進」。本研究沒有把整理、止跌、轉強重新混成同一個分類。

## 候選正面依據：可計算，但尚未組成偵測器

本批提出並計算的研究組合，是把以下證據一起保留，而非只統計已確認轉折點數：

1. 價格停留／重用：相鄰日範圍重疊與同價位涵蓋的完整日序來源。
2. 路徑方向：收盤淨移動、累積移動、方向及各尾段完整描述。
3. 末端位置：最近窗內高低距今幾筆、末收在觀察範圍何處；不得把窗高低直接變正式箱界。
4. 較大背景與來源資格：上漲中整理、相對舊帶更弱等已確認標籤，與當前原值分開。

對A，「反覆停留＋較廣路徑淨推進減少＋低點後回升」是可核支持證據；不是充分條件。對ABC，「已有自己的區間＋末端仍向下」是另一種相容組合，不能用A的回穩特徵強制排除它。hypotheses.json逐項記錄推論範圍與尚未建立的部分。

原2高2低／3%、6%、12%研究參數保持，沒有因本例調整；10/7沒有原核心快照，不能說本輪證明原分類器漏判、只有兩個轉折或已修好一個產品缺陷。
