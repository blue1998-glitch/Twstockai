# 多段活動的研究處理方式：整體觀察與局部身份可同時保存

2026-10-21。本輪為Work當前語意研究裁定，不冒充使用者新批准的正式交易規則或已驗證分類器。所有舊人工答案保持。

**可以把多段活動放在同一個較大過程中觀察，同時保留局部活動並列。** 「同一過程」不應直接等同於「局部結構合併成一個ID」。本輪把兩種關係分開，先解決合看就把局部身份抹掉的問題。

## 新觀察鏈至少要寫出什麼

本輪只規範研究紀錄，沒有把以下列成通用結構成立的必要充分條件。

1. **正在觀察哪個具體問題。** 例如ABC原較弱活動如何演變為離開28.45，不能只寫「它們看起來在一起」。
2. **用哪些已保存的實際路徑連接。** ABC保留6/2收破、6/3整根外及6/12才完成的下方活動，來源期與可知日各自留著；不以同價或時間靠近替代。
3. **哪些身份與舊答案不會因此改動。** ABC39、A已答情境、G2人工136及各局部ID保持。
4. **這條連結尚未證明什麼。** 因果、成功支撐／壓力、正式父子合併、主要性、正式起末成員與交易資格均未由此認證。

只看到同價、共來源、時間靠近、某價域包含另一價域，或候選數量變多時，先保留局部比較及來源關係；沒有證明的作用不升級。這是證據範圍管理，不是斷言它們永遠不能屬於同一結構。

## 程式可保存的關係與仍待定問題

本輪relationship-proposals.json是當前事後研究註記，不進歷史分類器、不作訊號輸入。

| 關係 | 用途 | 狀態 |
| --- | --- | --- |
| 既有人工整體情境 | 顯示已答A／ABC／G2背景，與局部證據同看 | 引用原答案，不新增人工裁決 |
| 跨段觀察鏈 | 追蹤某個原問題的已觀察演變，容許跨越原局部結構結束後的活動 | 研究連結提案；不是正式所有權 |
| 局部比較 | 記共同區、來源、相對位置等已證明關係 | 不因同屬背景就升級為反應或合併 |
| 正式結構身份合併／唯一父結構 | 決定局部是否真的變為一個結構，以及正式成員、起末與主要性 | 尚未定，不能由前三列自動推導 |

本輪真正縮小的核心未定項是**同層局部的正式合併判準**；較大觀察容器與局部身份已可分開管理。不是另發明一個大箱，把局部都吞進去。正式價界／父子／主次／反應仍null，historical_signal_eligible=false，分類器及新版Android未驗證，行動及飛輪效果未評估。
