# 已知價位的重訪片段：自動提案與當前位置分開

本輪已能從已有候選起日，自行提出「價格到另一側、再回來」的觀察片段，不先指定片段長度或正式箱界。**這是有正面路徑證據的觀察候選，尚不是已驗證的區間形成規則。** 較早的往返與當前位置分別保存，不能用其中一個替另一個作結論。

## 如何自行提出片段

1. 每個原有觀察種子往後讀取日K。某個低價、高價或收盤價第一次在該種子中出現時，才把它加入可用參照；保留原日期及低／高／收盤角色。同價重複出現不增加獨立票。
2. 只追蹤參照已出現後的完成收盤。收盤在參照上、到下、再回上，或在下、到上、再回下，便留下三段嚴格側向造訪的證據。相等不算跨越，原值保留，不推日內成交路徑。
3. 返回前就凍結從第一段造訪日至返回前一筆的原日K高低範圍，獨立比較返回收盤是否在其中。返回同側卻越出先前全範圍的情況另記「超出範圍」，不能把一次大幅穿越說成價格已回到原活動範圍。
4. 返回當日的影線可以伸出舊範圍。後來的每個截止另記目前收盤／整根日K對該舊範圍的位置，不覆寫原片段，也不強制決定正式停止／延續。

這種「往返」只證明一次同價位兩側的再訪，可能出現在雜訊、反彈或趨勢內；不能因三段造訪就稱區間成立。片段第一日、返回前框末日、證據完成日、原種子起日皆有不同意義，全部不是自動批准的正式起末。沒有改原2高2低、3／6／12%，也沒有新增百分比、等待天數或最短長度門檻。

遇原列待核缺日，新的參照與側向造訪重新從缺日後累積，舊片段保留；跨該處到最新截止的現值關係帶未認證標記。這只是資料疑點隔離，非市場結構重置，完整日曆／公司行動／歷史公開可得仍未核。

## 為何不用穿越次數直接判斷

唯讀診斷曾把兩個13筆觀察窗按完整窗收盤價間隙分格，兩者最多都穿越4次；這項計數無法表達末端走向，因此沒有採為門檻。該格點是事後診斷，不當歷史可用事件。現在的方法只用參照實際進入觀察之後的收盤，並保存每個證據完成日與當前關係。詳 [hypotheses.json](hypotheses.json)。
