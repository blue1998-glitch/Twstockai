## 一、情境及資料出處

使用者在對話中檢視一張助手生成的**模擬** A／B／C 三欄日 K 與成交量圖。圖分別題作 A「反彈」、B「動能修復」、C「真正重新轉強」，描繪跌破既有結構之後，由反彈、回收失土到突破上方壓力並再攻的不同完整歷史路徑。圖中紅色 K 上漲、綠色 K 下跌。本示意**非真實個股**，模擬價格與量柱不能當作已核行情、分類正例或具歷史成功率的數據；原使用者對話附件及圖留在聊天，未加入公開 Git。

使用者原文：

> 基本上ABC都對。至於問題3.的狀況很多，通常迅速跌很深卻沒有帶量上漲，都可能是假的，此時疑心較重，尤其是沒有突破最高量的量先價而行都不太算安全。

原助手後續曾將此答覆描述為「量未突破最高量，就不算安全」的普遍規則；此處以**使用者原句的條件性語境**為準，不能擅自寫成全市場量硬門檻。

## 二、已確認的結構方向

- A/B/C 三張示意圖的**定性判讀方向獲使用者認可**。A：反彈尚未恢復主要壓力／結構。B：以長紅或連續小紅回收部分失土，動能修復，但上方仍有壓力。C：突破先前重要壓力／收復關鍵區域，後續站穩並延續上攻，完整圖回顧可稱重新轉強。
- 上述標籤是**不同後續事實下的人工回顧描述**，不是僅看到 A/B/C 早期相似片段就能事先預知後續。按 P0-3，價格越過有效回檔高點／跌破有效原箱底的結構事實獨立更新，量的證據強弱不刪除此類客觀事實。
- **價格收復不代表舊賣壓已解除，更不保證值得立即重新持有**；成交量、K 實體及路徑、上方壓力與後續守價可影響證據品質與行動資格，不能只靠一個「收復=true」。

## 三、P1-6 特定新補充：快速深跌後的無量回升，疑慮更高

使用者指出：當**前一段跌勢又快又深**，後續雖然回升／收復價位，若**上漲成交量沒有跟隨**，可能只是假的修復或短暫反彈，因此人工主觀疑慮提高。尤其價格走在量能之前、**成交量尚未越過所比較價格帶的最高量參照**時，會認為重新持有的安全性尚不足。

這是**條件性的反面證據**，由「此前跌幅與跌速 → 回升路徑 → 量能與先前參照的比較」共同構成，不能退化為下列錯誤通則：
1. 「沒超越最高量＝沒突破成功／結構必定未轉強」：否。價格客觀越高就是越高，仍可有弱量突破及後續站穩；量主要影響支持程度／可疑程度及行動資格。
2. 「所有價格領先成交量＝一定是假突破」：否。僅是本答覆所指**特別在急速深跌後**須更小心的情境；沒有事實驗證時不可聲稱真假概率。
3. 「正式買入條件一定要超越最高量」：尚未經使用者要求，違反已答的 P0-4「只超密集量峰未超最高量＝仍觀察價格，不給直接負面解讀」，亦違反 P0-3「結構事實跟隨價位更新」。

就特定案例，`price_recovery_observed`、`structural_strengthening_observed`、`volume_confirms_momentum`、`selling_pressure_resolved`、`reentry_eligible` 必須分開。急跌後量價不協調可讓「重新持有」資格停留觀察／證據不足，但不應改寫當天價格的過線事實。

## 四、給數值引擎的候選欄位（工程推導，非已核公式）

- `prior_decline_speed`、`prior_decline_depth`：描述前一跌段的可見幅度與速度，不預設天數／百分比門檻。
- `recovery_path`：一根長紅／連續小紅／缺口／收復價區與上方壓力之相對位置。
- `volume_vs_cluster_peak` 與 `volume_vs_max_of_relevant_band`：兩道量參照分存，日期、截止、原量與單位分別記錄；不得以不明所屬量峰作比較。
- `price_leads_volume_in_sharp_drop_rebound_context`：候選可疑旗標，只適用證據範圍已符合該情境；不得直接判「假的」、提升為校準機率或一票否決。
- `evidence_quality`：支持／反面／未知證據及來源；與 `structure_state` 和 `action_eligibility` 隔離。
- `pressure_wall_role`：保留歷史大量所在價帶、之前是否破底、是否成功收復及後續守價；「解除賣壓」需相應證據，不能由收復一日自動標成功換手。

保留原 P1-5 裁決：高檔量**發生當下**未知是否成功換手，跌破箱底後才能把其意義更新為潛在套牢賣壓；後見意義不倒灌原歷史時點。保留 P0-2/3/4 各自已答規則，不能用 P1-6 取消客觀結構狀態或固定放量成功門檻。按使用者已定手動 Raw／Adjusted 模式，同一圖的價格、參照、指標使用同基底版本；量口徑獨立。
