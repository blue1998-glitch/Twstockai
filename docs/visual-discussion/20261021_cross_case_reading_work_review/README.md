## 本輪可保留的共同閱讀順序

1. 先核該參照／活動在當日是否可用，保留形成來源與可知日。
2. 分開記收盤相對單點、共同區、來源原高低的位置；相等不算嚴格跨過。
3. 整根在外、日K相交與收盤跨過分開；整根外不是更新觀察的必等條件，相交也不證日內先後。
4. 新完成活動在它可知時補入；不回填較早當日，不因時間經過自動加確定性。
5. 明確指出新證據改動哪句判讀，以及仍未跨過哪些較大參照；來源重用／同一行情衍生不能加成獨立票。

這是有限案例中一致的研究閱讀順序，不是新交易規則、通用必要充分條件或已核正式分類器。
