# 人工補充裁決：紫框在綠線高點突破時成立，量能使其優先於橘框

日期：2026-10-22。依使用者同一張 2024/01～08 **純模擬 K 線**彩色人工標註圖及文字說明。繼承先前 `../20261022_user_simulated_multilevel_box_evolution/README.md` 與下緣候選研究 `../20261022_multilevel_box_floor_review/README.md`。私有標註圖不加入公開 Git；本文不含真實 OHLCV、精確價格、逐筆量或已驗證訊號。

## 最新使用者原話

> 紫框成立時間點就是綠線高點那邊突破時，而且你可以看到紫框才有較高的量，因此才不看橘框。

## 對前輪助手提問的明確更正（優先於早期推測）

1. **紫框的成立時點**：使用者明示為「綠線高點那邊突破時」，而**非**等待綠色高點後回檔、形成數根平緩 K、再回測支撐才能宣稱紫框成立。其上下緣幾何與來源 K 應保留圖上人工定義；不以此一句推導固定 N 日／百分比。
2. **橘框與紫框的取捨**：左側相近低點可讓橘色大框作為較廣的幾何／支撐候選，但紫框所涉區間有**相對更高的成交量**，所以本案使用者**選紫框，不採橘框作主要分析框**。這不等於「因橘框較大所以永遠優先」，也不能一律將兩框視為同等有效的父子決策訊號。早期所說「橘框內有紫框」保留圖形空間關係，但**分析優先選擇**與**幾何包含**是不同欄位；「才不看橘框」不可被改寫成橘框仍是同等重要的正式主箱。
3. **量的作用**：在此次箱型取捨中，量能是區辨主要分析範圍的關鍵資訊，不只是在已選箱型後評論突破成功的附加欄位。以視覺人工判斷「紫框較高量」保存；未提供正式量比較範圍、最高單日量或密集量群演算法，不可擅填倍數／均量門檻，亦不因此推導「沒放量的突破必然失敗」。
4. **綠／藍關係**：依前輪已核人工圖，綠色新高突破藍色舊高、紫色較早帶與右側褐色新帶有前後關係；此輪補的是紫框辨認的事件時點與橘／紫量能優先選擇，不可擅改已答褐色含灰色小箱、右端紅線初破綠線待破的觀察。
5. **歷史重播不可偷看未來**：人工事後完成標註，回放時只允許用綠高突破時點及其之前已有的價格／量證據判斷當時可認出的紫色結構；綠高以後的回檔、完整褐箱與灰箱不能倒灌到紫框成立日。可有事後完整展示視圖與當時可知視圖，兩者分開。
