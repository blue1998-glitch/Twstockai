Android：下載ZIP → 在「檔案」解壓 → 以瀏覽器開啟 `Twstockai_CAP1_synthetic_demo_v01.html`。不需帳號、伺服器或行情連線。裝置是否允許本機HTML腳本尚待實機確認，不能把手機尺寸測試當成實機通過。

1. 點「續抱」「明示減碼」「退出B」，觀察同帳戶淨值、成本、回撤及持股。
2. 拖動日期到1/9，再到1/12；未交割現金不提前增加，原權利依日程交付。
3. 點「全退出持現金」應顯示資料不足；賣光B仍有C，不是假清倉。
4. 需要原始精度時打開「進階明細」下載合成JSON。
